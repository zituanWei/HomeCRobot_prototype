小护 · 家庭陪护机器人


一台跑在你自己电脑上的陪护机器人。它会看你、听你、跟你说话，也会在你需要的时候主动开口。

不需要云服务，不需要月费，不需要把家里的画面传到任何地方。


一、它能为你做什么


1. 你不用学怎么用，直接说话就行

不用找遥控器，不用打开手机应用，不用记住指令。
走到电脑前说一句「今天有点闷」，它就会接话。
说完停顿一下，它自己知道你说完了，不用按键。
这对不熟悉电子产品的长辈尤其重要，说话是唯一的学习成本。


2. 它认得你，不用每次自我介绍

第一次见面时，它会问：我好像还不太认识你，能告诉我你叫什么名字吗。
记住之后，你走近它，它会说「张奶奶，回来啦」；你问「我是谁」，它会答「你是张奶奶呀」。
一个人可以注册8 张照片，所以换个角度、换个光线，它也不容易认错。


3. 你还没开口，它可能已经注意到你

长时间坐在沙发上没动，它会问：要不要起来走两步。
连续几次没看到人，它会问：我有20 分钟没看到你了，一切都好吗。
它不会一直吵你。同一个人打完招呼后有冷却时间，安静的时候它就真的安静。


4. 家里没人说话的时候，它在那儿

它不会假装是个人，但它会陪你把话说完。
你说「我有点累」，它不会给你讲大道理，只会问要不要歇一会儿。


5. 你的画面和对话，不出这台电脑

这是这个项目最重要的设计选择。
视觉理解在本机模型上跑，语音识别在本机跑，语音合成可以完全离线，对话记录存在本地文件里。
断网也能用。摄像头拍到的画面、你和它说过的话，都不会被传到任何服务器。
对家里有老人的家庭来说，这一点比功能多更重要。


二、它做不到什么（也说清楚）

不夸大能力，这几件事目前确实做不好。

1. 关于摔倒识别
它能发现有人躺在地上很久没动，但姿态判断本身不可靠。
实测中正常坐着也可能被描述成躺在地上。
所以紧急提醒不会只看一次判断，必须是连续多次确认加语音询问没回应才触发。
它不能替代真正的跌倒报警器，只能算一层额外的辅助。

2. 关于情绪理解
目前没有情绪识别功能。它能听懂你说的话、看到你的表情，但不会判断你今天心情好不好。
这部分在技术文档里画了设计，代码还没写。

3. 关于小物件
画面里很小的东西它可能完全看不到。
它能看清大件的衣物、眼镜、耳机，但别指望它帮你找钥匙。

4. 关于多人场景
现在只能覆盖一个摄像头、一个房间，也分不清几个人同时说话时谁在说。


三、想自己跑起来


1. 需要什么
－ Python 3.10 以上
－ 一张 NVIDIA 显卡，8GB 显存可以跑3B 模型
－ 摄像头、麦克风、扬声器

2. 三步启动
第一步，安装依赖，执行 pip install -r requirements.txt
第二步，检查环境，执行 python check_env.py，它会告诉你显卡、摄像头、麦克风是否正常
第三步，启动网页版，执行 python web_server.py
然后用浏览器打开本机8000 端口，点启动系统，等模型加载完就能用。

首次一定要做麦克风校准，否则很可能出现说了话没反应的情况。
执行 python scripts/calibrate_mic.py --scan

3. 模型要自己下载
仓库里不含模型文件，体积太大。首次运行时会自动下载，也可以手动执行下列脚本。
下载视觉模型，执行 python scripts/download_model.py，约 7GB
下载本地语音合成模型，执行 python scripts/download_piper.py，约 60MB


四、功能一览

1. 看图对话。问「我头上戴着什么」它会拍照看，问知识类问题则不会浪费算力。
2. 人脸识别。一人可注册8 张照片，识别时取最高分。
3. 语音输入。麦克风常开，自动断句，无需按键。
4. 语音输出。三种引擎可切换，在线失败自动降级本地。
5. 主动关怀。1.5 秒一次的在场检测，有人来就打招呼。
6. 网页界面。对话、视频流、人脸管理、自定义头像。


五、里面用了什么

1. 视觉理解，Qwen2.5-VL 3B 模型，4 比特量化。
2. 人脸检测与识别，OpenCV 的 YuNet 与 SFace。
3. 语音识别，FunASR paraformer。
4. 语音合成，Piper 本地引擎，可切换 edge-tts 在线引擎。
5. 网页服务，FastAPI 与 WebSocket。

全部本地运行，无需任何 API Key。


六、常见问题


1. 为什么它有时候不理我
八成是麦克风设备选错了。Windows 的默认录音设备经常指向一个没信号的端点，比如蓝牙耳机的空闲通道。
启动时如果看到麦克风信号异常的黄色警告，就跑一次校准脚本。


2. 为什么响应有点慢
看图回答需要十几到几十秒，纯文字对话通常2 到 7 秒。
3B 模型在消费级显卡上就是这个速度，想更快可以换更小的模型或者只关闭视觉通道。


3. 它会一直录我说话吗
麦克风确实常开，这是随时能插话的代价。
但它只在检测到有人说话时才做识别，安静时不会处理音频。
如果你完全不想被听，网页上可以点麦克风按钮关闭监听。


4. 能装在树莓派上吗
不行。需要独立显卡来跑视觉模型，普通电脑也要有8GB 显存。


七、项目状态

这是一个实习期完成的项目，核心功能可用，但仍在迭代。

已实现的部分包括视觉对话、人脸识别、语音输入输出、主动关怀、网页界面。
规划中的部分包括情绪识别、跨应用调度、唤醒词、长期记忆。

详细的技术说明见项目文档。
